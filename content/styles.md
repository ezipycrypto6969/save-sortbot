# Marketing styles log

The Sunday content run reads this with `stats/summary.md` and updates it every week. Each style has a short name used as the reel's `"style"` field.

## Regular styles

| Style | What it is | Model reels | Weekly slots |
|---|---|---|---|
| `base` | Owner's main format. The saved-reel problem first, SaveSort shown early, then genuinely useful info from the saves, balanced with the product. | `2026-11-01-3-needs-the-video`, `2026-10-30-2-comment-guide` | about 14 |
| `funny-ad` | Funny product ad. Sorty, one running joke, quick walkthrough of the sorter, strong end card. | `2026-10-29-3-rip-saved-tab` | about 4 |

## Experiments

Each week runs 3 experiment reels (1 to 3 new styles). Name them `exp-<short-name>`. Record each one here: start week, idea, result.

| Style | Started | Idea | Status | Result |
|---|---|---|---|---|

## Experiment ideas (general public, marketing-focused, no fake people or testimonials)

- `exp-pov`: relatable POV ("POV: you open your saved tab looking for one recipe").
- `exp-before-after`: the messy saved tab, then the sorted SaveSort list.
- `exp-myth-fact`: one viral claim from a saved reel, then what's actually true.
- `exp-challenge`: "I did one saved reel a day for a week" style, only with real, checkable results.
- `exp-signs`: "3 signs your saved tab is a junk drawer".
- `exp-question`: asks viewers one question to comment ("How many saves do you have?").
- `exp-stitch`: reacts to a common type of reel (paraphrased, no real creator named).
